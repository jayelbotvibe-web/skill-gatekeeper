Skill Gatekeeper Architecture

Mode-based skill filtering for AI agents — 110→17 skills, 32% smaller system prompt

Detection Engine

  • • Keyword scoring — zero API calls
  • • 9 modes, ~45 keywords each
  • • Multi-word phrases: all words must match
  • • Sub-millisecond latency

Filesystem Manager

  • • shutil.move() — atomic on same FS
  • • Preserves directory structure
  • • O(1) per skill operation
  • • State persisted to JSON

Safety Guarantees

  • • Files moved, never deleted
  • • --reset restores everything
  • • Score < 2 → falls back to all
  • • Agent cannot self-modify config
